# POV Rajput 0.2.20

## New

- **Auto-play size limit.** Turn it on in **Settings → Playback** and set the largest file Auto-play may pick, such as 20 GB. With highest quality and largest file first, Auto-play plays the biggest link at or under your limit. You can still choose any link yourself.
- **Title logo while paused.** Pausing shows the movie or show's logo in the top-left corner of the player.

## Improved

- **Posters load much faster.** Artwork downloads several at a time over reused connections, and is kept on the TV, so it appears straight away on later visits. New titles still load their own artwork.
- **Back hides the player controls first.** A second Back goes to the mini player.
- **Debrid API keys show what went wrong.** If a Real-Debrid, AllDebrid, Premiumize or Debrid-Link key can't be checked or saved, the key box stays open with the reason. Thanks to Muhammad Abubakar for this fix.
- **The update screen matches the rest of the app,** with formatted release notes.
